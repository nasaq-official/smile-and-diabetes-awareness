# ابتسامتك وسكّرك
إعداد: راكان علي محمد الأسمري — الأسبوع الخليجي للسكري، جامعة الطائف.

## التشغيل
افتح index.html مباشرة في متصفح حديث. لا يلزم تثبيت أي مكتبات. يعمل المحتوى والتفاعل دون اتصال؛ يحتاج خط Google الاختياري والمراجع إلى الإنترنت، مع وجود خط بديل محلي.

## GitHub Pages
1. أنشئ مستودعًا باسم smile-and-diabetes-awareness.
2. ارفع محتويات هذا المجلد إلى جذر المستودع بحيث يظهر index.html في الجذر.
3. في Settings > Pages اختر Deploy from a branch، ثم main و / (root) ثم Save.
4. افتح الرابط الذي يعرضه GitHub بعد اكتمال النشر.

## الملفات
index.html وstyle.css وscript.js ومجلد assets للشعارات؛ أزيلت خلفية شعار Smile Club لتنسجم مع التصميم.
قائمة العادات مؤقتة وتُصفّر عند إعادة تحميل الصفحة.
السن رسم توضيحي بتدرجات SVG ومنظور CSS وليس نموذجًا تشريحيًا أو محاكاة مرضية.
المراجع الطبية وروابطها داخل الموقع. المحتوى لا يستبدل الاستشارة الطبية.
